# Referência de Rotações Simia

[Site Base de Consulta das Rotações do Simia](https://auth.simia.pro/data/rotations.html)

**Descrição:**
Este site é a base de consulta das rotações de todos os usuários do Simia. Ele pode ser utilizado para pesquisar e entender o que outros usuários estão fazendo, servindo de inspiração e auxílio para descobrir o que é possível fazer nas suas próprias rotações.
